# ManMen

Cinematic ecommerce experience built with Next.js App Router, Tailwind CSS, GSAP (ScrollTrigger + ScrollToPlugin + SplitText), Lenis smooth scrolling, and Zustand cart state.

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

## Routes

- `/` cinematic storytelling homepage
- `/shop` animated product listing with filters
- `/product/[slug]` product detail with gallery and cart actions
- `/cart` cart management and totals
- `/checkout` premium checkout UI
